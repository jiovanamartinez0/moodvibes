# MoodVibes Mini App
 
**Author:** [Chris Martinez]  
**Course:** CIS-107: Comprehensive Web Development  
 
## Description
MoodVibes is a responsive web application designed to help users explore aesthetic color palettes and custom quotes tailored to their daily feelings. It features interactive vibe cards, a dynamic quiz with live feedback, and a form allowing users to submit their own custom mood ideas.
 
## Features Included
- **Display Questions:** Interactive quiz that displays mood questions dynamically.
- **Choose an Answer & Score Tracking:** Option buttons track score upon selection.
- **Progress Bar & Question Counter:** Visual indicators show current quiz progress.
- **Per-Answer Feedback:** Immediate message after selecting an answer.
- **Restart Button:** Users can reset and retake the quiz.
- **Responsive Layout:** Works smoothly across both desktop and mobile devices.
- **Accessibility:** High-contrast text and explicit HTML image alt tags.
 
## Technical Details
- Built with HTML5, CSS3 (CSS Grid & Flexbox), and Vanilla JavaScript.
- Documented project architecture, database considerations, and security policies on `other.html`.
